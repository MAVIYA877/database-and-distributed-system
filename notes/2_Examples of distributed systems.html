Simple Java Client-Server ExampleNow move from simulation to actual network communication

Step-by-Step Implementation

Create a ServerSocket on port 5000

This opens a listening endpoint that waits for an incoming client connection.

Block on accept()

The server pauses execution until a client actually connects — a real network handshake.

Read from the socket's input stream

Wrap the stream in a BufferedReader and read the line the client sends.

Create the Client and connect

The client opens a Socket to "localhost" on the same port, 5000.

Write a message via PrintWriter

The client sends a line of text over the socket's output stream to the server.

Run server first, then client

The server must be listening before the client attempts to connect, or the connection will be refused.

Server.java
import java.io.*;
import java.net.*;

public class Server {

    public static void main(String[] args) throws Exception {

        ServerSocket serverSocket = new ServerSocket(5000);

        System.out.println("Server started...");
        System.out.println("Waiting for client...");

        Socket socket = serverSocket.accept();

        BufferedReader input =
                new BufferedReader(
                        new InputStreamReader(socket.getInputStream()));

        String message = input.readLine();

        System.out.println("Client says: " + message);

        socket.close();
        serverSocket.close();
    }
}
Client.java
import java.io.*;
import java.net.*;

public class Client {

    public static void main(String[] args) throws Exception {

        Socket socket = new Socket("localhost", 5000);

        PrintWriter output =
                new PrintWriter(socket.getOutputStream(), true);

        output.println("Hello Distributed System!");

        socket.close();
    }
}
